🌍 Zaminex Microservices Backend

Zaminex is a scalable land-selling platform designed for Tier 2–3 cities. This repository contains the microservices-based backend architecture that powers listings, users, transactions, and more.

🚀 Overview
This project follows a microservices architecture to ensure scalability, maintainability, and independent deployment of services.

Each service handles a specific domain:

User Management ,
Property Listings

🏗️ Architecture
Microservices Pattern

API Gateway for routing requests

Service-to-Service Communication (REST)

Database per service
